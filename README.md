# 抽水蓄能机组剖切交底图工具

React + Fabric.js 实现的剖切交底图合成工具:把厂家总装图的设备编号、安装高程和尺寸标注合成到剖切视图上。

## 运行

```bash
npm install
npm run dev        # 开发
npm run build      # 构建到 dist/
npm run preview    # 预览构建产物
```

## 使用流程

1. **导入底图** — 工具栏「导入总装图」「导入流道图」,图片进入底图层(默认锁定,解锁后可拖动)。
2. **标定** — 填好转轮直径 D1 米数,点「①转轮直径」后在图上点直径两个端点;再填安装高程,点「②安装高程」后在图上点高程线。底图自动摆到 转轮中点 x=0、安装高程 y=0 的世界坐标,并画出红色高程基准线。
3. **剖切** — 「画剖切线」沿流道拉线,「生成/更新剖切视图」把底图沿线旋转裁出带状剖面,单独成层;拖动橙色端点可改剖切位置,视图自动重生成。
4. **编号标注** — 右侧粘贴图签(每行 `编号,名称,安装高程`)或加载示例,逐台「贴标」或「全部贴标」。标注按安装高程自动落到对应高度,可拖动、可改字号(选中后工具栏改),并绑定剖切视图随其移动。
5. **尺寸标注** — 「尺寸标注」模式下在蜗壳/尾水管控制尺寸处拖出尺寸线,文字自动按标定换算长度;两端圆形控制柄可再调端点;线宽/箭头/字高在右侧「尺寸图例」统一修改。
6. **图层** — 底图 / 剖切视图 / 编号标注 / 尺寸标注 四层独立显隐和锁定,锁住的层点不中。
7. **撤销/重做** — Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y,一次拖动手势记一步,不按每次 mousemove 记。
8. **框选** — 选择模式下拖框可选一组标注,整体平移/缩放;缩放后标签字号、尺寸端点自动烘焙,位置不跑偏。
9. **导出** — 「导出交底图」按当前图层显隐状态输出 PNG,含图名、比例尺(随缩放换算)、指北针和设备编号表。

## 操作提示

- 滚轮缩放(以鼠标为中心),空格+拖动或「平移」模式平移画布。
- Delete 删除选中对象;双击编号标注可改文字。
