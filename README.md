# 机关传动件程序化出件工作台

使用 **SolidJS + Babylon.js + TypeScript** 构建的齿轮 / 齿条 / 栅格遮挡件程序化出件工具。设计师从供应商提供的模数、压力角出发，调整整组参数、单独覆盖某些齿轮齿数，在 3D 场景中旋转检查啮合，并导出下料清单、安装坐标和装配说明。

## 启动

```bash
npm install
npm run dev
```

打开终端输出的 `http://127.0.0.1:5173/`。

生产构建与本地预览：

```bash
npm run build
npm run preview
```

纯逻辑测试：

```bash
npm test
```

## 已实现的关键流程

1. **供应商基础规格**：模数 `m`、压力角 `α`、齿形（渐开线 / 梯形 / 圆弧）。
2. **整组基础参数**：齿轮数量、基础齿数 `z₀`、整组间距 / 栅格节距 `S`、齿厚、轴孔。
3. **即时 3D 生成**：Babylon.js 拉伸生成带孔齿轮轮廓、配套齿条和前后两片栅格；左键旋转、滚轮缩放、右键平移。
4. **局部齿数覆盖**：
   - 每个稳定件号 `G1…Gn` 可单独调齿；
   - 手调齿轮在列表和 3D 中为橙色；
   - 覆盖保存在独立的 `overrides: Record<gearId, teeth>` 中；
   - 修改整组间距只重算派生坐标，不写回齿数，因此手调值不会被冲掉。
5. **栅格厚度依赖**：最大条厚为  
   `t_max = min(40, floor(min(0.42S, S - 12)))`。  
   缩小间距导致当前厚度超限时，会弹出提示并立即钳制到可用上限。
6. **种子复现**：种子驱动确定性的减重孔数量、孔径和相位。模型指纹由规范化后的完整参数、覆盖和派生模型哈希得到；测试保证同参数、同种子、同覆盖的 `JSON.stringify(model)` 完全一致。
7. **方案比对**：可保存多个方案快照到 `localStorage`，在“两版比对”中查看参数、手调齿数、指纹和 BOM 总量差异。
8. **批量出件**：批量套数会乘入 BOM 总数；“整排批量刷新”会一次性重建齿轮、齿条和栅格。
9. **施工交付**：右侧“下料 / 装配”页可导出：
   - Markdown 下料清单 + 装配说明；
   - Excel 可打开的下料清单 CSV；
   - 全部件号的安装坐标 CSV；
   - 用于完全复现的工程 JSON。

## 坐标约定

- 原点：首套传动组几何中心；
- `X`：沿齿条长度方向；
- `Y`：竖直向上，`Y=0` 为齿条齿距基准线；
- `Z`：齿厚方向，`Z=0` 为齿轮厚度中心；
- 前后栅格中心位于 `Z = ±(齿厚/2 + 净距 + 栅条厚度/2)`。

## 核心代码

- `src/lib/design.ts`：参数边界、确定性随机、布局、栅格约束、BOM 和指纹。
- `src/lib/gearGeometry.ts`：齿轮 / 齿条 2D 轮廓与孔环。
- `src/lib/exporters.ts`：Markdown、CSV、JSON 和下载。
- `src/state/store.ts`：Solid 全局状态、局部覆盖、钳制提示、方案快照。
- `src/viewer/BabylonViewer.ts`：Babylon 场景、拉伸件、栅格、拾取和相机。
- `src/components/`：参数面板、齿轮覆盖面板、交付面板和方案比对弹窗。
