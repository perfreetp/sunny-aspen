# 火山喷发阶段编排台

用 **Svelte 5 + PixiJS 8** 做的火山喷发阶段动画编排工具。面向科普展陈团队与演示喷发过程的研究人员：
把一次喷发的多个阶段讲清楚，最后交付可交互的演示页面或汇报视频。

## 运行

```bash
npm install
npm run dev      # 开发服务器（默认 127.0.0.1:5173）
npm run build    # 产出 dist/
npm run preview  # 预览构建结果
```

浏览器要求：Chrome / Edge 120+（导出 WebM 需要 WebCodecs）。

## 核心概念

一条**按阶段推进的时间轴**，每个阶段挂一帧画面，三条轨道：

| 轨道 | 内容 | 可调参数 |
|---|---|---|
| 锥体形态 | 按野外产状的锥体剖面 | 位置 dx/dy、缩放 sx/sy、色调 |
| 熔岩流前缘 | 沿锥坡下泄、越过锥缘进入平地的熔岩流 | 前缘位置 front、带宽、dx/dy |
| 火山碎屑层 | 披覆在锥坡与地表的一层碎屑 | 厚度、覆盖率、dx/dy |

**时间基是帧**。阶段内所有关键帧以**归一化 u∈[0,1]** 存储，因此：

* 改某阶段时长 → 该阶段内节奏自动重排，后续阶段整体平移；
* 熔岩前缘两个打点之间的插值天然跟着重排，无需手动修关键帧。

## 工作流

1. **新建动画**：按喷发类型（斯通博利式 / 普林尼式 / 夏威夷式 / 武尔卡诺式 / 熔岩穹丘）铺好阶段序列。
2. **按野外产状填锥体**：把锥体图鉴里的形态**拖到时间轴的阶段条上**，或用检查器点选。
3. **叠影校对**：上一阶段锥体以半透明虚线叠在当前画面上，当前阶段的新锥体与熔岩流画在上面；
   拖动位置、拉右下把手缩放，直接检查新老覆盖关系。
4. **逐帧微调**：`←` / `→` 逐帧，`Shift+←/→` 十帧；发现熔岩前缘压过锥体边时点**退一格叠看**，
   上一帧轮廓以黄线叠出，量出差多少再拖回来。
5. **编组**：检查器里「锥体＋碎屑层 编组」后，拖任意一个会一起挪。
6. **打点**：熔岩流前缘可在任意帧单独打点（检查器「打点」），前后帧按打点插值推进。
7. **交付**：`导出动画` → 独立播放器（给展陈）/ WebM（给汇报）/ 逐帧采样数据（给研究分析）。

## 键盘

| 键 | 作用 |
|---|---|
| `空格` | 播放 / 暂停 |
| `←` / `→` | 退 / 进一帧 |
| `Shift+←/→` | 十帧 |
| `Home` / `End` | 首帧 / 末帧 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 撤销 / 重做 |
| `G` | 切换上一阶段叠影 |
| `Ctrl+Enter` | 打开导出 |

## 一致性保证

编辑器预览、逐帧检查、回放、视频导出、独立播放器，全部走**同一条采样路径**：

```
doc + frame → sampleScene() → 图元列表 prims → StageRenderer（PixiJS）→ 画面
```

`sampleScene` 是纯函数、无副作用、零依赖，所以「松手后的回放」与「拖动预览」在结构上必然一致，
而不是靠两套代码人工对齐。视频导出只是在离屏画布上复用同一个 `StageRenderer`。

## 目录

```
src/lib/
  geom.js        锥体/坡面/轮廓几何（纯函数，轮廓与熔岩坡道共用一个坡面公式）
  presets.js     野外产状图鉴、喷发类型模板、碎屑层预设
  doc.js         工程文档模型、关键帧插值、编辑操作
  scene.js       场景采样器：把 (doc, frame) 采成绘制图元
  render-pixi.js PixiJS 渲染器（池化 Graphics/Text）
  store.svelte.js 编辑器状态（Svelte 5 runes）
  export.js      单文件播放器 / WebM / 逐帧采样
src/components/  StageView · Timeline · Inspector · TopBar · ExportDialog
src/player/      独立播放器入口（构建期打成单文件内联）
tools/           引擎自检、分层调试、播放器内联插件
```

## 自检

```bash
node tools/selftest.mjs   # 采样引擎断言：无 NaN、阶段重排幂等、越界单调
```
