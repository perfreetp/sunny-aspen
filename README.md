# 温室灌溉管网接出工具

给设施农业技术员的平面出图工具:从水源首部起,沿棚体布主管、按支管间距分叉、在支管上排滴头与喷头,
并按流量和压力分段校核。React + TypeScript 做界面与状态,Paper.js 做矢量绘制,水力计算是独立、
可单测的纯函数模块。

```bash
npm install
npm run dev        # http://localhost:5173
npm run test       # 24 个核心单元测试
npm run build      # 类型检查 + 生产构建
```

## 功能对应

| # | 需求 | 实现位置 |
|---|------|----------|
| 1 | 首部起画主管、沿棚纵向到棚尾、管径按设备参数选 | `core/layout.ts` 主管几何;`core/hydraulics.ts` `designMainDiameters` 按压力预算选径,首段取技术员设定的首部管径,向下逐段变径 |
| 2 | 主管上按支管间距自动分出支管、贴着苗床走向 | `nominalBranchUs` 等间距分叉;`followBeds` 把支管吸附到苗床中线(`buildBeds` → 床中线上取点,单调不重复) |
| 3 | 每条支管按滴头流量/间距自动排滴头,喷头区段按射程排布 | `buildEmitters`;喷头间距 = 射程 × 间距系数 |
| 4 | 按流量压力沿管分段,超允许压降的段标黄并提示加粗/缩短 | `buildSegments`(Hazen-Williams + 局部损失)、`designAllowableDrop`;黄色段 + `Warnings` 面板给出 `换 DNxx / 缩短到 x m` |
| 5 | 改上游主管管径 → 下游自动重算,手调支管与滴头保留 | 水力每次从 `params + overrides` 全量重算;手动位置/间距存在 `ProjectDoc.overrides`,与水力解耦 |
| 6 | 拖一个滴头改间距 → 只影响这一条支管 | 拖动落点换算成该支管的 `branchSpacing` 覆盖项,只写这一条支管的 key |
| 7 | 布置种子:同参数重生成完全一致 | `core/prng.ts`(mulberry32 + 每条支管独立随机流);布置指纹见工程面板 |
| 8 | 首部接水源处标压力分段,每段末端挂压力标注 | `buildPressureZones` 每降一档或变径即切段;图面压力牌 + 纵剖面 + 底部压力条 |
| 9 | 检查支管穿作业道,红框圈出并列出清单 | `findAisleConflicts`;画布红框 + 「穿道清单」页签(含「移开」一键修正) |

## 计算口径

- **沿程摩阻**:Hazen-Williams,`C` 默认 130(PE),局部损失按沿程的 12% 计。
- **支管允许压降**:由目标出流偏差反算。`q ∝ h^x` 时 `Δh/h = 1 − (1 − d)^(1/x)`,
  `d = 10%`、`x = 0.5` 得约 19% 工作水头;支管同时有滴头和喷头时取两者更严的一个。
- **主管允许压降**:按工作水头的百分比设置(默认 40%),选径时以「本段 + 下游全部剩余段」的
  累计摩阻为约束挑最小可用管径,首段固定为技术员选的管径,只向下变径。
- **出流偏差**:按灌水器类型分别统计,不把 2 L/h 的滴头和 250 L/h 的喷头放在一个平均值里。
- **不确定性**:滴头位置抖动与支管位置抖动都由种子驱动,每条支管一条独立随机流,
  因此增删其他支管不会改变这条支管的排布。

## 交互

- 滚轮缩放(以光标为中心)、空白处拖动平移、`复位`回全图。
- 点支管选中;拖动支管改其沿主管的位置(记为该支管的手动定位)。
- 放大到滴头能分开时,拖动滴头改这条支管的滴头间距;或在支管面板直接输入间距。
- 所有手动修改都在工程面板计数,可一键清除;改管径、改种子时保留。

## 产出

- `导出 SVG`:图面矢量图,可直接进图纸。
- `导出 CSV`:分段水力计算表、灌水器清单、穿作业道清单、材料表(UTF-8 BOM,Excel 直接打开)。
