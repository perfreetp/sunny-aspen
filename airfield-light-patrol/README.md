# 机场灯光要素巡视工具

面向飞行模拟机视景生产流程的机场灯光要素巡视工具：视景系统工程师导入机场测绘资料，按要素类别铺成可缩放/平移/旋转的机场周边灯光图；教员在图上巡视、点查要素、调整远距离简化档位、框选缺灯段；最终把地景要素配置与缺失清单打包成交付给模拟机运维的场景要素包。

## 技术栈

- **Svelte 5**（runes 响应式）+ **Vite 6**
- **PixiJS v7.4** WebGL 渲染 + **pixi-viewport v4.38**（缩放/平移/旋转/惯性）
- **JSZip** 场景要素包打包

> Pixi 主版本锁定 v7：pixi-viewport v4 官方适配 v7；v7 的渲染器自动探测只检查 WebGL1，引擎内改为显式创建 WebGL `Renderer` 注入，兼容 WebGL2-only 环境。

## 启动


## 功能与角色

### 视景系统工程师
- 测绘资料导入（内置 23,842 个灯光要素的合成数据集，结构等同实测导入：3 条跑道方位、34 条滑行道/高速出口、96 个机位、4 套 ICAO 进近灯光构型）
- 11 类要素各归独立图层：跑道边灯/中线灯/接地带灯/入口灯、滑行道边灯/中线灯/警戒与停止排灯、进近灯、机坪照明、障碍灯、边界灯
- 每类要素配置两级简化阈值（抽稀 m/px、聚合 m/px）与最低显示级别，图层独立开关
- 配置 JSON 导入/导出/复位

### 教员
- 双视图并排：全机场视图 + 局部巡视视图，任一视图选中要素，另一视图自动飞行定位并高亮
- 点击要素弹出编号、所属灯组、组内序号、局部坐标、经纬度、状态；右侧虚拟滚动要素列表同步高亮（2.4 万行不卡顿）
- 阈值滑杆实时调整全局简化强度，工程师面板同步显示当前档位
- Ctrl + 拖拽或工具按钮旋转视图，HTML 标注按四方位候选点碰撞避让自动重排（旋转后零重叠）
- 框选疑似缺灯的滑行道段，系统按线路/侧别分组检测内部断号，列出缺失编号

### 闭环交付
- 缺失清单支持工程师一键补录关闭
- 「打包场景要素包」导出 ZIP：`feature-config.json`（地景要素配置）、`missing-list.json/.csv`（缺失清单含框选坐标）、`README.txt`

## 渲染性能设计（数万要素流畅缩放平移）

| 机制 | 说明 |
| --- | --- |
| 空间网格索引 | 250m 网格，拾取与视锥遍历只扫描覆盖网格 |
| 视锥剔除 | 每帧按视口四角外包矩形单遍扫描，屏外要素零开销 |
| 三级 LOD | LOD0 完整灯组 → LOD1 按 designIndex 步长抽稀 → LOD2 按网格聚合为锚点；阈值按 m/px 与每类配置计算 |
| 对象池 | Sprite 按类别池化复用，缩放平移只移动/显隐，不创建销毁对象 |
| 共享纹理 | 同类灯共用一张圆点纹理 + tint，绘制调用最少 |
| 虚拟列表 | 右侧要素列表只渲染可视行（34px 行高 + 超采样） |
